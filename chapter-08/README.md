# Chapter 8 — Event Handling & User Input

This chapter focuses on **responsive input**: multi-key tracking, smooth movement with **velocity & friction**, **direction + thrust** steering, **mouse clicks/drags**, and combining input types. Capstone: **Simple Pong**.

## Files
- `01_key_single_press_limit.py` — shows the limits of basic `onkey`
- `02_key_states_full.py` — robust key-state dictionary (Up/Down/Left/Right)
- `03_key_states_compact.py` — loop + lambdas to bind keys (cleaner pattern)
- `04_velocity_movement.py` — velocity, friction, smooth acceleration
- `05_direction_steering.py` — rotate with Left/Right, thrust with Up
- `06_mouse_click_move.py` — click-to-move (and follow variant)
- `07_mouse_drawing_drag.py` — left-drag to draw, right-click to stop
- `08_keyboard_mouse_combo_game.py` — keyboard player vs. mouse target
- `09_pong_starter.py` — two players, paddles + ball (you finish it)
- `10_pong_solution.py` — complete Pong (reference implementation)
- `11_challenge_asteroid_field_starter.py` — Try-It project
- `12_challenge_paint_program_starter.py` — Try-It project
- `13_challenge_catch_falling_starter.py` — Try-It project
- `replit/main.py` — quick “Chapter 8 Ready!”

All worked answers live in `solutions/` too.
