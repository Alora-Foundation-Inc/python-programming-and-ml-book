# Chapter 7 — Intro to Game Programming

This chapter turns your Turtle skills into simple **games**: animation loops, bouncing, collisions, a game loop, game state, and two capstone games (Dot Collector and Avoid the Obstacles).

## Files
- `01_turtle_tag_basic.py` — first tiny game: move with keys, random target
- `02_turtle_tag_with_scoring.py` — tag + left/right + collision + score
- `03_smooth_animation_intro.py` — manual animation with `tracer(0)`/`update()`
- `04_bouncing_ball_horizontal.py` — bounce left/right
- `05_bouncing_ball_2d_starter.py` — starter: bounce on all 4 walls
- `06_game_loop_template.py` — the classic 4‑step loop
- `07_chasing_game_full.py` — chase a moving target, score points
- `08_collision_distance_demo.py` — `.distance()` demo
- `09_collision_interactive_color_change.py` — move + detect + color feedback
- `10_game_state_basics.py` — dictionary state: score/lives/level
- `11_dot_collector_starter.py` — capstone #1 starter
- `12_dot_collector_solution.py` — capstone #1 full solution
- `13_avoid_obstacles_starter.py` — capstone #2 starter
- `14_avoid_obstacles_solution.py` — capstone #2 full solution
- `15_target_practice_starter.py` — try‑it: click targets
- `16_snake_head_movement_starter.py` — try‑it: snake head movement
- `17_memory_game_starter.py` — try‑it: simple Simon‑style game
- `replit/main.py` — “Chapter 7 Ready!”

All solutions are also duplicated inside `solutions/` for convenience.
