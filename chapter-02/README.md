# Chapter 2 — Python Basics Through Art

This chapter introduces **variables**, **for loops**, **lists**, and **nested loops** using Turtle art.

## Files
- `01_movement_basics.py` — forward/back/left/right basics
- `02_coordinates_goto.py` — `penup/goto/pendown` and (x, y)
- `03_pen_control.py` — color, pensize, shape
- `04_variables_square_hexagon.py` — side length & angle with variables
- `05_for_loop_square.py` — first loop-drawn square
- `06_for_loop_polygons.py` — triangle & hexagon via loops
- `07_list_colors_triangle.py` — loop over a **list** of colors
- `08_nested_growing_squares.py` — nested loops: 5 bigger squares
- `09_simple_spiral.py` — 91° spiral with growing steps
- `10_list_sizes_multiple_squares.py` — sizes list + nested loop
- `11_rainbow_polygon.py` — rainbow sides + angle = 360/sides
- `12_circle_art.py` — 6 overlapping circles (pinwheel)
- `13_exercise_rainbow_polygon_starter.py` — student starter
- `14_exercise_star_pattern_starter.py` — student starter

> Tip: Keep indentation consistent (4 spaces). End scripts with `turtle.done()`.
