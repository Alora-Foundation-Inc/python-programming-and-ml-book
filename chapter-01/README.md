# Chapter 1 — Welcome to the Visual Programming World

These examples are **loop-free** and **function-free** (perfect for first-timers).

Run any file with `python filename.py` (or press **F5** in Thonny).  
If a window closes too quickly, make sure `turtle.done()` is at the end.

Files:
- 01_hello_turtle_window.py — opens the window and draws a short line.
- 02_square_basic.py — your very first square.
- 03_square_sizes.py — same square, three different sizes.
- 04_triangle_and_angle_variations.py — triangle and angle experiment (no loops).
- 05_color_and_pensize.py — color + thicker pen.
- 06_two_squares_move_goto.py — draw, move, draw again.
- 07_simple_pattern_three_squares.py — tiny “pattern” using only repeated commands.
- 08_tip_keep_window_open.py — why `turtle.done()` matters.
