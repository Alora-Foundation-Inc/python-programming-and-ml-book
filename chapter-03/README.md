# Chapter 3 — Loops: The Magic of Automation

This chapter explores **for loops**, **while loops**, **nested loops**, **loop control (break/continue)**, and **basic animation** with Turtle.

## Files
- 01_review_square_with_for.py — quick review: drawing a square with a for loop
- 02_pentagon_with_range_print.py — understand `range()` and loop counter `i`
- 03_range_variants_reference.py — demo of start/stop/step and reverse counting
- 04_growing_squares_no_lists.py — loop variable controls size (range start/step)
- 05_two_lists_circles_wave.py — sizes + colors lists synchronized with index
- 06_challenge_growing_spiral_starter.py — student starter challenge
- 07_nested_grid_squares.py — 4×5 grid of squares with nested loops
- 08_nested_triangles_colors.py — outer loop colors + inner loop triangle
- 09_flower_garden_nested.py — flowers and petals with nested loops
- 10_while_spiral_until_max.py — while loop grows until condition met
- 11_while_safe_with_counter.py — safety counter prevents infinite loop
- 12_while_rainbow_spiral.py — color cycling using modulus (%)
- 13_challenge_shrinking_squares_starter.py — student starter challenge
- 14_break_spiral_boundary_stop.py — break out when beyond boundary
- 15_continue_skip_every_third.py — continue to skip selected iterations
- 16_break_and_continue_combo.py — both tools in one pattern
- 17_anim_bouncing_ball.py — basic position update + wall bounce
- 18_anim_rotating_radar.py — spin/clear/sleep animation
- 19_anim_growing_spiral_timed.py — animated spiral with timed color shifts
- 20_challenge_rainbow_squares_starter.py — nested loops practice

- 25_fibonacci_squares_spiral.py — Fibonacci-sized squares forming a spiral
- 26_nested_loop_art_layers.py — triple-nested loop layered hexagon art

> Tips
> - Keep indentation consistent (4 spaces).
> - Always end with `turtle.done()` so the window stays open.
> - For animation, use small `time.sleep()` values (0.01–0.1 s).
