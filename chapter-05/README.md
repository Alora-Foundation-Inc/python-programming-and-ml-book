# Chapter 5 — Data Structures: Organizing Your Information

This chapter upgrades your code from scattered variables to **lists**, **lists of lists**, and **dictionaries**, then adds **conditional logic** and **file saving/loading** so your programs keep their data.

## Files
- `01_problem_messy_variables.py` — shows why scattered variables are painful
- `02_lists_garden_basics.py` — parallel lists for flower data + looped drawing
- `03_indices_reference.py` — how list indices refer to related info
- `04_list_operations_demo.py` — append/insert/remove/len/in membership
- `05_dynamic_star_field_starter.py` — starter: stars with lists of props
- `06_list_of_lists_garden.py` — garden as a **list of lists**
- `07_list_of_lists_add_remove.py` — add/remove whole items
- `08_dicts_garden.py` — garden using **dictionaries** for clarity
- `09_dict_methods_demo.py` — keys/values/in/get/pop reference
- `10_conditionals_artworks.py` — choose drawing via if/elif on `type`
- `11_boolean_garden.py` — AND/OR/NOT to decide plant “health”
- `12_file_save_garden.py` — save garden data to a `.txt`
- `13_file_load_garden.py` — load garden data back from a file
- `14_safe_file_ops.py` — safe save/load with `try/except`
- `15_challenge_art_collection_starter.py` — capstone #1 starter
- `16_challenge_smart_garden_starter.py` — capstone #2 starter
- `17_challenge_pattern_library_starter.py` — capstone #3 starter
- `replit/main.py` — quick “Chapter 5 Ready!”

> Tips
> - Lists use `[]`, dictionaries use `{}`.
> - Lists are 0-indexed.
> - Use `try/except` for file I/O.
> - End drawing scripts with `turtle.done()`.
